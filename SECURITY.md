# Security Policy

## Supported Versions
We actively patch and support the following versions of our projects:

| Version | Supported |
| ------- | --------- |
| Main    | ✅ Yes    |
| v1.x    | ❌ No     |

## Reporting a Vulnerability
If you discover a security vulnerability, please do NOT open a public issue. Instead, report it securely by:
1. Emailing the details to: security@digitcharms.com
2. Providing a clear description of the issue and steps to reproduce it.

We will acknowledge your report within 48 hours and keep you updated on the fix.
